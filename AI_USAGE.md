## Review and Changes

The generated approach was reviewed against the supplied assignment before packaging.

Important implementation choices:

- Pagination follows the actual `Next` link rather than hard-coded page numbers.
- Source-specific parsing is kept separate.
- Cleaning is kept independent of internet access.
- Validation returns specific rejection reasons.
- Duplicate fingerprints use normalized identifying fields.
- A failure in one source is isolated from the other source.
- Category and description are not invented when they are not available from the listing page.
- The scraper uses retries and a polite request delay.

## Testing

The test suite covers:

- whitespace and quote cleanup
- price and rating conversion
- tag normalization
- URL validation
- missing-name validation
- invalid-rating validation
- invalid-URL validation
- duplicate detection with case and whitespace variations

Run:

```bash
pytest -q
```

The live websites could not be reached from the build environment because outbound DNS/network access is unavailable there. The live dataset is therefore intentionally generated by the user-side `python main.py` run rather than fabricated.
